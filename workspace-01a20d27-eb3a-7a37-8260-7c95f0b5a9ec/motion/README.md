# 3D-шортс «Куда уходят токены» — как это сделано

Полностью процедурный ролик: 3D-рендер, типографика, пост-обработка и музыка
генерируются кодом (никаких стоков, шейдер-паков и сэмплов).

## Файлы

| файл | что делает |
|---|---|
| `engine.py` | мини-3D-движок на OpenGL 3.3 (moderngl): GGX-освещение, PBR-металлы, shadow map, туман, DOF, bloom, ACES-тонмаппинг, зерно, виньетка. Меши: rounded box, box, cylinder, sphere, torus, plane |
| `overlay.py` | 2D-слой: шрифты (растеризация в PNG-слои), плашки, glow, счётчик токенов, прогресс-бар, blooming + grain пост |
| `scene.py` | таймлайн ролика: 7 сцен, камера по ключевым кадрам (dist / высота цели / наклон / FOV), анимации объектов с пружинным овершутом, тексты оверлея |
| `audio.py` | синтез саундтрека: пэд (Am–F–C–G), саб, пульс, кик, хэты, whoosh/pop/click SFX, свёрточный реверб |
| `out/short_v1.mp4` | готовый ролик 1080×1920, 24 fps, 10.0 с, H.264 + AAC |
| `out/soundtrack.wav` | отдельная звуковая дорожка |
| `out/poster.png` | кадр для обложки |

## Как перерендерить

```bash
pip install moderngl numpy pillow fonttools imageio-ffmpeg
cd motion
python3 scene.py test 1.2,3.5,6.6      # отдельные кадры -> out/f_*.png
python3 scene.py video                 # все 240 кадров -> out/frames/
python3 audio.py                       # -> out/soundtrack.wav
ffmpeg -framerate 24 -i out/frames/%04d.png -i out/soundtrack.wav \
       -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest out/short.mp4
```

## Скорость

llvmpipe (софтверный GL, 2 ядра): ~2–4 с на кадр 1080×1920 ⇒ ~12 мин на 10 с.
На машине с GPU (или на EGL + реальная видеокарта) тот же код идёт в 10–20 раз быстрее.
